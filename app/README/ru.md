# Идея проекта и мой вклад в него

“Мой холодильник” - это мобильный компаньон, который помогает домочадцам следить за тем, что находится внутри холодильника, избегать пищевых отходов и мгновенно готовить что-нибудь вкусное из того, что там уже есть. Я реализовал проект от начала до конца: от UX‑flow и чистой модульной архитектуры MVVM до Android‑приложения на базе искусственного интеллекта и серверной части для семейного использования

[english](https://github.com/winipux21/MyFridge/blob/master/README.md) [русский](https://github.com/winipux21/MyFridge/blob/master/app/README/ru.md)

Моими главными задачами было:
* Архитектура – Jetpack Compose UI + навигация, уровни репозитория/вариантов использования, пространство для автономного хранения, база данных Firebase Realtime для синхронизации с облаком и выделенный шлюз искусственного интеллекта
* Основные функции – просмотр списка продуктов и покупок, распознавание штрих‑кодов / фотографий, генератор рецептов, управление семейным рабочим пространством и ролями
* Интеграция искусственного интеллекта – конечная точка OpenAI Vision (фото продуктов из холодильника) и DeepSeek LLM для создания рецептов с учетом контекста.  
* Безопасность и аутентификация – вход в Google с обновлением‑ротация токенов, зашифрованные общие предпочтения для локальных секретов
* Совместная работа в режиме реального времени ‑ семейные рецепты / продукты синхронизируются через прослушиватели Firebase 
* Конвейер действий CI & QA – GitHub, модульные тесты / UI (JUnit5 + Compose‑UITest), охватывающий 80% логики

# Концепция проекта
* На входе и в главном меню ‑ после авторизации в Google пользователь попадает на главный экран с тремя вкладками: "Холодильник", "Список покупок", "Рецепты"  
* Вкладка “Холодильник” – в локальной базе данных номеров отображаются все товары с указанием количества, единицы измерения и срока годности; а также кнопки для добавления вручную или "по фотографии"
* Список покупок — простой чек-лист с возможностью удаления свайпом и переключения статуса 
* Вкладка "Рецепты" – выберите тип блюда / режим диеты, и DeepSeek вернет 1-3 персонализированных рецепта, используя только свежие продукты
* Семейное рабочее пространство – делитесь холодильником, списками или одним рецептом с родственниками; владелец может переименовать или удалить семейное пространство
* Распознавание фотографий – сделайте или выберите снимок, приложение вызовет OpenAI, получит сообщение “[Молоко 1 шт СГ 7 дней]” и запишет элементы прямо в базу данных

## Демонстрация проекта 
* Холодильник + боковое меню. Главная вкладка показывает актуальные продукты с количеством и сроком годности; сверху — кнопка «Добавить через фото», снизу — FAB «+» для ручного ввода. Чёрточка‑меню на аватаре открывает быстрый доступ к профилю, личным/семейным рецептам и выходу из учётки
* Карточка рецепта. Развёрнутый рецепт из сохранённых: название, компактный список ингредиентов и пошаговые инструкции на одной карточке — можно сразу начать готовить, не переключаясь между экранами
* Профиль. Пользователь меняет аватар одним тапом, редактирует никнейм и сохраняет его в Firebase; отдельная кнопка открывает настройку времени напоминаний о продуктах
* Семейное пространство. Экран «Детали семьи» показывает ID‑код для приглашений, общие продукты/рецепты/список покупок и даёт владельцу права переименовать или удалить семью, а также шарить отдельные сущности одним кликом
